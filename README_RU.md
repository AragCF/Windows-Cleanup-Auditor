# Ревизор дискового мусора для Windows

**Версия 0.2.0**

Утилита сначала исследует выбранный локальный диск или все фиксированные диски, показывает найденные объекты по категориям, размеру и степени риска и только затем позволяет удалить явно выбранные объекты.

## Степени риска

- **Безопасно** — временные данные и промежуточные результаты, которые обычно создаются заново.
- **Восстанавливаемое** — кэши и загружаемые зависимости, удаление которых может потребовать повторной загрузки или сборки.
- **Осторожно** — объекты, которые программа никогда не выбирает как безопасные автоматически: виртуальные среды, `node_modules`, локальные `.ipa`, скачанные установщики и архивы и т. п.

Исходный код, `.git`, Android SDK и Flutter SDK целиком, AVD, ключи, пользовательские документы и системные хранилища Windows не считаются мусором.

## Запуск

Для первого прогона:

```bat
scan_only.bat
```

Этот режим **ничего не удаляет** и сохраняет JSON/CSV в `reports\`.

Графический режим:

```bat
start_cleanup.bat
```

BAT-файлы версии 0.2.0 записаны в ASCII с окончаниями CRLF и **не вызывают `chcp`**. Они не меняют кодовую страницу, шрифт или привычный вид `cmd.exe`; русский интерфейс находится в Python-приложении.

## Что распознаётся

Windows TEMP и CrashDumps; Gradle/Android; Flutter/Dart; Python; Maven; npm/Yarn/pnpm; NuGet; Cargo; CMake; кэши Android Studio/JetBrains/VS Code; промежуточные каталоги проектов.

Отдельно учитываются:

- `Flutter SDK\bin\cache` — восстанавливаемый кэш; сам Flutter SDK целиком не удаляется.
- `Android\Sdk\.temp` — временные загрузки Android SDK Manager.
- верхнеуровневые ZIP/7z/RAR/EXE/MSI рядом с Android SDK — показываются по одному как **«Осторожно»**; это часто старые установщики и архивы, но решение остаётся за пользователем.
- локальные `.ipa` внутри профиля iMazing — показываются по одному как **«Осторожно»**. Их удаление с компьютера не удаляет уже установленное приложение с iPhone, но уничтожает локальную копию для будущей переустановки.

Каталоги `ndk`, `build-tools`, `platforms`, `platform-tools` и сам `flutter` внутри SDK — это рабочие компоненты, а не мусор. Удаление устаревших версий таких компонентов должно быть отдельной осознанной операцией.

## Публичный Git и журналы

`logs/` и `reports/` исключены через `.gitignore`: в них могут попасть имя пользователя, пути и названия проектов.

Для передачи результатов:

```bat
pack_reports_for_git.bat
```

Нужен установленный 7-Zip. Упаковщик запрашивает пароль во время запуска (либо читает `WCA_REPORT_PASSWORD` из окружения), создаёт `encrypted_reports\WCA_reports_*.7z` с AES-256 и шифрованием имён файлов (`-mhe=on`). Пароль в репозитории не хранится. Исходные открытые отчёты автоматически не удаляются.

## Безопасность удаления

Перед удалением цель повторно проверяется. Запрещено удаление корней дисков, системных корней, ссылок/точек повторного разбора и объектов внутри систем контроля версий. Для категории **«Осторожно»** требуется дополнительное подтверждение словом `УДАЛИТЬ`.

## Проверки 0.2.0

В среде разработки подтверждены синтаксис Python, самопроверка правил, защитные проверки удаления, обнаружение Android/Gradle/Flutter/Python, локальных iMazing IPA и архивов рядом с Android SDK, исключение `.git`, а также ASCII+CRLF для BAT-файлов.

Запуск через настоящий `cmd.exe`, отображение графического окна и реальное удаление на рабочей Windows-машине должны быть подтверждены отдельной полевой проверкой.
